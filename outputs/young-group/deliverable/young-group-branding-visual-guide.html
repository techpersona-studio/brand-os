01 — Visual north star

What this brand must feel like

The brand should feel like: A trusted Vietnamese nutrition coach you'd believe enough to spend money on — warm, specific, and present from the first scroll to the first result.

Not like: A generic wellness brand, a clinical weight-loss program, or an aspirational lifestyle ad.
One-line visual thesis

"Warm espresso and ivory authority — proof-first, founder-led, and nothing like a wellness ad."

Anchor adjectives
Trusted
Specific
Warm
Anti-adjectives
Generic
Clinical
Aspirational

Desired emotional response

Understood

"This person knows what Vietnamese women actually go through."

Convinced

"These results are real. That number and that name match what I want."

Protected

"If it doesn't work, I won't lose my money. There's a guarantee."

Why this direction fits Young Group's trust burden is high. The primary audience has tried and failed at multiple weight loss programs. Every visual choice must signal: this is real, this is specific, this is for you. The warm espresso-and-ivory system reads as established, human, and credible — without expensive visual complexity. It creates immediate tonal distance from blue-and-white clinical wellness and from aspirational green lifestyle brands.
02 — Direction mix

Enterprise / Stable leads

Enterprise / Stable — 65% Editorial / Human — 35%

The visual system leads with structure and proof: espresso-on-ivory hierarchy, clean grid, trust-first components. The Editorial layer provides warmth: founder portrait, Lora italic voice moments, named proof chips that feel personal. Structure earns trust. Warmth makes it human.

What this mix prevents

  • Aspirational lifestyle imagery that distances from real results
  • 50/50 balance — hedging produces visual blandness
  • MLM-adjacent visual language (before/after collages, gradient CTAs)
  • Clinical wellness language (blue/white, medical iconography)
03 — Color system

Seven colors. One accent.

Warm neutrals carry 65–70% of every view. Espresso anchors authority. Near-black handles text. Bronze-gold earns its punch by appearing rarely — never above 5%.

07 — Proof presentation

Honest, specific, structured for trust

High trust burden. The buyer has tried and failed before. Vague testimonials don't move her. Specific, named, attributed results do.

Proof typeFormat rule
TestimonialsNamed · located (US state or country) · exact weight numbers · testimonial-card format
CredentialsBook authorship · 226K followers (exact) · 6-country reach (listed)
GuaranteeTwo distinct locations: hero area + founder block · Lora italic · bronze-gold accent
Founder proofPortrait + direct voice quote + guarantee restatement · founder-slab component
Before/afterNever in before/after collage format — use named testimonial cards only
Fabricated proofNever · no invented client count, certifications, or rounded testimonial numbers

Above-the-fold rule

At least one trust element must be visible without scrolling on both desktop and mobile: guarantee badge, follower count, or one proof line. The trust anchor band (espresso background) appears immediately after the hero.

What must never be fabricated

  • Review counts or star ratings without a verified source
  • Named client results without explicit written permission
  • Any testimonial without a real name and real location
  • Rounded numbers ("hundreds of clients" without confirmation)

09 — Motion and interaction

Restrained. Purposeful. Never decorative.

Motion rules

Card hovertranslateY(−4px) + shadow deepen · 500ms spring
CTA button hovertranslateY(−1px) · 150ms ease · background darkens
Scroll revealopacity 0→1 + translateY(16px→0) · 400ms ease-soft
Button icontranslate(2px,−2px) on hover · diagonal signal
Propertiestransform + opacity only — never layout properties
Reduced motionRequired guard on every animation

What must never animate

  • Proof numbers, weight-loss metrics, or timeframes
  • Guarantee amounts or follower counts
  • Background color transitions on scroll
  • Looping or ambient animations
  • Parallax on any image
  • Floating persistent widgets
Why proof must never animate Animating proof numbers signals the numbers are fabricated. The buyer has been burned before. Static specificity reads as honest.

11 — Do / Don't rules

Blunt. Visual. Operational.

Do

  • Lead every section with an outcome or proof element — never a feature list
  • Use the founder's face prominently in hero and personal-voice sections
  • Show exact numbers — weight lost, timeframe, follower count; rounds read as invented
  • Repeat the guarantee in at least two distinct page locations
  • Render testimonials as named cards: name · location · X lbs in Y weeks
  • Use warm ivory and deep espresso as the primary visual system; bronze-gold at 5% max
  • Keep one primary CTA action per viewport section — never stack two
  • Render Vietnamese text at Be Vietnam Pro 400 minimum at all sizes
  • Treat 226K Facebook followers as a trust anchor — prominent placement, never footer
  • Ensure CTA, guarantee, and one proof element are visible above the fold on mobile
  • Use Lora italic for founder-voice moments — the brand's signature typographic move
  • Use the double-bezel testimonial-card for all proof modules — no flat cards
  • Alternate warm ivory and warm stone sections to guide scroll rhythm

Don't

  • Use generic wellness stock photography — women on scales, green smoothies, measuring tape
  • Use blue-and-white or green-and-white as anchor palette
  • Show before/after collages in transformation or MLM format
  • Lead with program features before proof and outcomes
  • Use condensed or aggressive headings — Lora is the authority signal
  • Animate proof numbers, testimonial metrics, or guarantee amounts
  • Use the script font for anything other than the founder name signature
  • Use English-first layout conventions, imagery, or cultural cues
  • Add any second accent color — bronze-gold is the only accent
  • Introduce more than one Lora italic gesture per section
  • Use Be Vietnam Pro below 400 weight for Vietnamese text
  • Put the guarantee in fine print or footer — it is a headline-level trust element
  • Use pure white #FFF as page background or pure black #000 as body text
  • Use bronze-gold as a large section background or introduce a second accent

13 — Implementation notes

What must be preserved. What can flex.

Must preserve exactly

  • All color token hex values — reference via CSS custom property, never hardcoded hex
  • Double-bezel testimonial-card structure — outer shell + inner core + inset highlight
  • Founder-slab in dusty rose — the highest-trust element, never recolor
  • Island button — pill shape, inner icon wrapper, hover magnetic drift
  • Section background sequence — never two adjacent sections the same shade
  • Be Vietnam Pro 400 minimum for all Vietnamese text — no exceptions
  • Bronze-gold at 5% maximum — audit before adding new uses
  • Reduced-motion guard on every animation
  • Warm ivory --paper as page background — not pure white #FFF
  • Lora italic for founder-voice moments — one per section maximum

Accessibility

  • All interactive elements: :focus-visible ring using --anchor
  • Color never the only information carrier — pair with shape, weight, or label
  • All images: descriptive alt text. Portrait: "Trần Thủy Tiên, Young Group founder"
  • Form labels: visible, never placeholder-only
  • Reduced motion: required on all animations
  • Minimum tap target: 44×44px on all buttons
  • Vietnamese diacritics: test Be Vietnam Pro at 16px on ivory before shipping
  • Bronze-gold not used for small body copy on ivory — insufficient contrast

Future agents must never

  • Introduce colors outside the locked palette
  • Add a second accent color for any reason
  • Replace Lora with another serif display font
  • Use Be Vietnam Pro below weight 400 for Vietnamese text
  • Use gradient or glassmorphism on any primary surface
  • Apply hard offset block shadows — soft warm-tinted depth only
