## 5. Trust and proof system

- **Primary trust signal:** 226,000 confirmed Facebook followers — display as a number, not a social icon
- **Proof types to use:** Named testimonials (name + state + lbs + weeks); exact weight ranges (0.5–1 lb/day, max 50–60 lbs); health outcome testimonials (diabetes, blood pressure, lipids); 226K follower count; double money-back guarantee in two distinct forms; service area (6 countries)
- **Proof types to avoid:** "Hàng nghìn khách hàng" as final copy (placeholder only — replace with specific count when confirmed); before/after collage format; generic wellness stock photography; animated proof numbers; any fabricated urgency mechanism
- **Proof that appears early:** 226K follower count + guarantee callout in hero viewport; first testimonial proof chip above first scroll; trust bar immediately below hero
- **Proof that appears later:** Full testimonial expansion on Results page; FAQ answers with cited specifics; founder credential bar on About page; guarantee block on Program page
- **Site-wide proof modules:** Trust bar (226K + client count + guarantee + 6 countries); proof chip cluster component ([Name], [State], [X lbs in Y weeks]); CTA band with guarantee reminder; founder block with guarantee restatement
- **Proof blockers / missing assets:** Specific client count not confirmed — blocks replacing "Hàng nghìn" everywhere; founder credentials beyond book authorship — flag on About page; book publication status unconfirmed (partial only); video testimonials unavailable now; countdown timer broken — remove before launch; Facebook link wrong — correct to canonical fanpage before launch
