# Branding Visual Guide — Generator Handoff

## North star

Trusted Vietnamese coaching authority — warm, proof-first, and nothing like a wellness ad.

## Direction mix

* Primary direction: Enterprise / Stable — 65%
* Secondary influence: Editorial / Human — 35%

## Locked color system

* Base: Warm ivory / champagne — `#F5EFE4` approximate
* Neutral: Warm stone / taupe — `#D9CDBF` approximate (alternating section background)
* Anchor: Deep espresso brown — `#3B2314` approximate (headings, borders, authority elements)
* Text primary: Near-black warm — `#2C1A0E` approximate
* Accent: Bronze-gold — `#B8903A` approximate (logo mark, CTA highlights, proof emphasis only)
* Secondary: None — two-tone system; no secondary color field
* Usage ratio: Neutrals 65–70% / Espresso 20–25% / Bronze-gold 5%

Note: Hex values approximated from visual asset inspection. Confirm from original brand kit before final delivery.

## Locked typography system

* Display / headline font: **Lora** — hero headlines, section leads, guarantee callouts, proof kickers; confirmed from visual assets
* Body / UI font: **Be Vietnam Pro** — all running copy, proof chips, navigation, form labels, CTA button labels, testimonials; Vietnamese diacritic support first-class
* Script font: **Great Vibes** (or Dancing Script — confirm on Vietnamese diacritic rendering) — founder signature only; one instance per layout context; no other use
* Usage ratio: 65% Be Vietnam Pro / 30% Lora / 5% script
* Tone: Human / Warm
* Hierarchy: Strong
* Heading behavior: Sentence case; normal tracking; calm weight (Lora at 24px minimum)
* Body behavior: Plain; direct warm tone; Be Vietnam Pro Regular (400) minimum — never below 400; light weights break Vietnamese diacritics

## Locked layout rhythm

* Layout mode: Flow-based
* Rhythm: Alternating — warm ivory and warm stone sections alternate for breathing room and scroll guidance
* Density: Balanced
* Hero structure: Text + portrait — founder face in hero; outcome-first headline in Lora
* Section patterns:
  1. Full-width narrative (hero — problem acknowledgment + outcome promise)
  2. Proof band (testimonial cluster — named, numbered, located)
  3. 2-column (benefit left, evidence right)
  4. Founder block (personal voice + guarantee statement)
  5. CTA band (consultation booking — repeated at 2–3 strategic points)

## Locked component language

* Overall feel: Soft / Rounded
* Card language: Shadow-led — warm depth; no flat cards
* Button language: Filled; rounded rectangle; premium — espresso fill, ivory text; bronze-gold hover state
* Form language: High-trust; warm field styling; clear Vietnamese labels; no chrome excess
* Navigation feel: Quiet / Direct — must not compete with conversion flow
* Proof modules:
  1. Testimonial cards (named, numbered, located)
  2. Results chips (weight + timeframe stamps)
  3. Trust banner (226K followers + guarantee + service area)
  4. Founder note (personal voice, guarantee context)
  5. Credential bar (book authorship, platform reach, six-country reach)
* Signature component: Proof chip cluster — "[Name], [US State] — [X lbs in Y weeks]"; groups of 3–4; warm ivory shadow-led card; espresso name label; Be Vietnam Pro body

## Locked imagery direction

* Photography direction: Founder-led — real photography confirmed from provided assets; no stock photography
* Subject priority: People > Proof > Place
* Mood: Warm, Intimate, Clean
* Lighting: Natural, Soft
* Composition: Medium; Polished with documentary warmth
* Illustration / icon direction: Minimal outline icons for process section only — espresso stroke; no decorative illustration

## Locked motion level

* Level: Restrained
* Role: Reveal / Hover
* Button interaction: Tactile — subtle espresso-darken or bronze-gold ring on hover; no scale jumps
* Scroll behavior: Fade-up — section reveals on scroll
* What should never animate: Proof numbers, testimonial metrics, guarantee amounts
* Reduced motion: Required — prefers-reduced-motion must be respected

## Signature move

Lora italic for founder-voice moments — quote leads, guarantee callouts, one personal kicker per section maximum.

## Do / Don't rules

### Do

1. Lead every section with an outcome or proof — never with a feature description
2. Use the founder's face prominently in hero and personal-voice sections
3. Show exact numbers (weight lost, client count, follower count) — round numbers read as invented
4. Repeat the guarantee in at least two distinct locations in the page flow
5. Render testimonials as named proof chips: [Name], [State], [X lbs in Y weeks]
6. Use warm ivory base and deep espresso brown as the primary visual system; bronze-gold for mark-level accents only
7. Keep CTAs to one primary action per viewport section
8. Render Vietnamese text at sufficient size and weight — Be Vietnam Pro 400 minimum at all sizes
9. Make the 226K Facebook follower count visually prominent — treat it as a trust anchor, not footer detail
10. Ensure CTA, guarantee, and a proof element are visible above the fold on mobile

### Don't

1. Use generic wellness stock photography (women on scales, green smoothies, measuring tape, workout gear)
2. Use blue-and-white or green-and-white as anchor palette — clinical and generic wellness signals
3. Show before/after collages in the transformation or MLM style
4. Lead with program features before proof and outcomes
5. Use condensed or aggressive headings — Lora is the authority signal; do not add weight pressure
6. Animate proof numbers or testimonial metrics
7. Use the script font for anything other than the founder name signature
8. Use English-first layout conventions or English-centric imagery
9. Add a secondary accent color — bronze-gold is the only accent; additional colors break the premium register
10. Introduce more than one signature typographic or component pattern per section

* Actual font specimen (Lora display scale, Be Vietnam Pro body scale, script at signature scale) with Vietnamese diacritic examples
* Section rhythm specification or diagram

* Imagery rules (photography direction with explicit do/don't examples, icon style)
* Do / don't list
* Mockup directions (hero, proof band, CTA band, founder block — minimum 4 sections)
* Design tokens (color, spacing scale, typography scale, border radius, shadow values)

## Generator constraints

What the generator must not do:

* Invent business facts (client count, founding year, credentials not confirmed)
* Introduce colors outside the locked ivory + espresso + bronze-gold system
* Use generic SaaS or wellness defaults (minty greens, clinical blues, feature grids)
* Contradict the trust-first conversion model with aspirational or effort-forward visual choices
* Use Be Vietnam Pro below 400 weight for any Vietnamese text
* Use Lora below 24px in the body context
* Use the script font for any element other than the founder name signature
* Over-stylize beyond the Enterprise/Stable + Editorial/Human direction mix
* Produce any imagery direction that requires stock photography in the generic wellness category
